## 二、硬件侧：等你决定的（🔵）

### 2.1 MPR121 的 PMOD 接口 —— ✅ **2026-10-28 已定案**（信号级 + 物理针号都定了）

> **结论**：全部走 **`J6`（PMOD0，2×6 / 2.54 mm）**。
> 逐针表与接线细节见 `P2_飞线输入方案.md` §四之二，要点：
> **VCC=pin1/2(+3V3)、GND=pin3/4、SDA=pin9(IO2/G21)、SCL=pin10(IO3/G22)、IRQ 不接（轮询）**、
> **ADDR 必须接 GND（地址 0x5A，RTL 写死）**。`IO0/IO1`（pin11/12）**SOM 侧没有 ball，不能用**。
> 唯一待做的：**插之前用万用表复核 pin1/2 是 3.3 V、pin3/4 是 GND**（原理图还原值，未实物复核）。


现状：`.cst` 里那套（`sda=G21 / scl=G22 / 八度−=F18 / 八度＋=E18 / 滑音=C22`）来自 P2 文档，
**是候选接法，不是实测**。RTL 只要求"4 个 3.3 V 的 IO + 附近有 GND"，换脚只需改 `.cst` 那一段。

**换脚时必须满足**（`.cst` 里已写成注释）：

1. **3.3 V bank**（BANK2/3/4/5/10 可以；**BANK6/7 是 1.5 V DDR3 专用，绝对不能碰**）
2. 不与音频（Y17/AB17/AA16/Y14）、时钟（V22）、复位（F4）、板载键（AA13/AB13）、RGB（U12/V13/G11）、串口（U15）冲突
3. I2C 两根相邻、附近有 GND，线长 ≤ 15 cm
4. 三个机械键另一端接 GND（靠 FPGA 内部上拉）

**顺带记下**：`PMOD0_IO0/IO1` 早期文档写作 V18/V19，但 pintable 里查不到 → 已作废；
`PMOD0_IO7 = B22` 还空着，可作第 4 个机械键（例如颤音深度开关）。

## 四、本轮修掉的问题（调试记录）

| # | 问题 | 症状 | 修法 |
|---|---|---|---|
| 1 | `key_scan` 八度钳位写死 3，而 P2 允许 4 档 | **按第 4 档还是 C5**，静默少一个八度 | 改成参数 `OCT_MAX=4`；tb 补 2 条断言 |
| 2 | 两个 `generate` 循环共用同一个 `genvar` | iverilog 不报错，频率字总线整条 X | 用独立的 `gi/gk` |
| 3 | 频率字寄存器堆用"32 个小 generate 各写一段 wire" | 各块数值正确，但**整条总线是 X** ⇒ 相位累加器被污染后永久 X ⇒ **上电全静音** | 改成单个 always 写 reg 向量 |
| 4 | `top_console` 把 `INIT_FILE` 写死 | 在 `08_P1` 下仿真时 `$readmemh` 找不到 hex → ROM 全 0 | 提成参数，tb 传 `../06_keyboard/wavetable_all.hex` |
| 5 | `.p2_input_top` 的 `GLIDE_SHIFT` 参数被误接成同名输出线网 | 编译报 "not allowed in a constant expression" | 传常量 4'd12 |
| 6 | `top_console` 里 `vib_on_m`/`vib_depth_m` 先用后声明 | 编译报错 | 先声明、§10 再赋值 |

| 7 | 阻尼滤波器 `c_rd − lp` 在 **16 位**里相减溢出回绕 | RT60 只有设计值的 80%（1.19 s vs 1.5 s），尾巴偏"干、刺" | `$signed(a)-$signed(b)` **不会**因为赋给更宽的 wire 而变宽，必须**显式符号扩展**后再减 |
| 8 | 定点截断让 RT60 系统性偏短 21% | 公式给 1.5 s、实测 1.18 s | 反馈系数按 `RT60_cal = target/0.79` 标定，并在文件头写清"改 RT60 要重算这 4 个 Q15" |
| 9 | RT60 用**宽带**能量测 | 量出 1.0 s（把阻尼造成的高频快速衰减算进去了） | RT60 按惯例是**低频**段 ⇒ 先 4 极低通（~150 Hz）再累计 |
| 10 | 硬等 −60 dB | 16 位噪底在 −45~−50 dB 顶住，量到的是噪底 | 改 **T30 外推**（测到 −30 dB 的时间 ×2），这也是 RT60 的标准量法 |

| 11 | Gowin 工程**没设顶层** | 综合日志 `Current top module is "uart_rx"`，资源 49 LUT、BSRAM 0，P&R 的两个约束文件都是 `---` | 设 Top Module = `top_console` + 加 `.cst`/`.sdc`；**判据：rpt.txt 里两个约束文件不再是 `---`** |
| 12 | Console 的 RGB 有 2 路是**配置专用脚** | `PR2017`：`LEDs[0]`(U12/READY)、`LEDs[2]`(G11/DONE) 不能当普通 IO | LED 端口收成 1 位 `led` → V13(SYS_ACT)，低有效；要三色得开 dual-purpose pin |
> 第 2、3 条都属于"**仿真不报错、上板全静音**"那一类，而且**只有顶层集成 tb 才能抓到**——
> 这正是本轮补 `tb_top_console` 的价值。
