# 鱼妖合成器 / fpga_yuyao_synth

> 高云选题二　实时多音色合成电子乐器引擎

一台**不含 CPU、不含软件**的 32 声部复音数字合成器，全部功能由一片 Gowin GW5AST-LV138PG484 FPGA 实现。上电即进入演奏状态。

演奏输入是 12 电极电容触摸面板（MPR121，I2C，10 bit ADC）加 2 个板载键；输出是标准 I2S 送给 MAX98357A 功放。

## 参数

| 项目 | 值 |
|---|---|
| 器件 | Gowin GW5AST-LV138PG484AC1/I0（PBG484A） |
| 系统时钟 | 50 MHz（V22） |
| 采样率 / 位宽 | 48 kHz / 16 bit |
| 声部数 | 32（0–15 特殊池 2×osc，16–31 波表池 1×osc，共 48 个振荡器） |
| 时序收敛 | Fmax **53.840 MHz**，Logic Level 9，Setup/Hold 均零违例 |
| 最差 slack | +1.43 ns |
| 资源 | BSRAM 301/340、DSP 141/298、LUT 22.4 K（含 ALU 33.7 K，25%）、寄存器 18 467/139 095 |
| I2S | 标准 I2S，32 BCLK/帧，BCLK 1.536 MHz |
| 混响 | Schroeder，4 梳状 + 2 全通，RT60 1.39 s，可旁路 |
| 串口 | 115200 8N1，状态行 `K=xxx O=n D=n` |

## 设计上的几处取舍

**异构声部池。** 0–15 号槽每槽 2 个振荡器，可在「基波 + 二次谐波」加法音色与「锯齿调制正弦」2 算子 FM 音色之间切换；16–31 号槽每槽 1 个振荡器，正弦/方波/锯齿/三角四页波形可任意指定。

**能移位就不乘。** 包络用指数逼近的加/减/移位递推，演示态 1/N 音量归一化用右移，混音饱和用比较器卡边界。32 声部只占 141 个 DSP。

**复音数可现场自证。** 一个板载键把系统切进「数峰」演示态：强制正弦、零调制指数、按素数序列分配频率、每声部幅度按 1/N 缩放。频谱仪上能一根一根数出 1/2/4/8/16/32 根谱线。

**帧边界统一提交。** 同一条 48 kHz 节拍贯穿全链，所有控制参数在帧边界由 `param_xfer` 统一提交，频率字在整帧内恒定，从根上消掉参数突变的咔哒声。

## 验证

- 899 项单元回归（去抖、按键映射、频率表、振荡器、包络、混音、混响、I2C 事务、顶层集成）
- 26 项板级集成检查
- 全部通过后才进布局布线

## 上板要点

**`sys_rst_n` 接 F4，属 BANK7，电平 1.5 V，`.cst` 必须写 LVCMOS15。** 误配成 3.3 V 会烧 IO。

`$readmemh` 的路径是相对仿真器工作目录（综合时相对工程目录）找的，找不到**不报错**，ROM 全 X——仿真里满屏 X，上板全静音。上板时 hex 与本文件同目录，保持默认即可；在别处跑仿真要显式传路径。

`MIX_SHIFT` 默认 1（−6 dB 余量）。试过改 0，结果是干声满幅叠湿声、每音削波。想更响请改硬件（MAX98357A 的 GAIN 脚），别降这个值。
